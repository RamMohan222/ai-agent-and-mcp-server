# ai-agent-and-mcp-server
A simple implementation of an AI Agent and MCP server.


0. Run the model locally using Ollama or llama.cpp.
1. Run `src/main/java/com/ai/mcp/server/HTTPServer.java` to expose the tools through the MCP server.
2. Then run  `src/main/java/com/ai/client/TestClient.java` to send the prompts.
